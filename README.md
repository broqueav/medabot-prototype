# MedaBot — Interactive Prototype

**[▶ Open the prototype](https://broqueav.github.io/medabot-prototype/)** · best viewed on desktop

An AI medication assistant that explains medicines in plain language, adapts its answers to the health profile of each family member, and refers people to a healthcare professional when the risk is high.

The interface is in Portuguese, because the product was designed for the Portuguese market.

## Suggested paths

1. **Safety alert:** Iniciar Sessão (Log in) → Continuar com a Apple (simulated login, no data needed) → search "Plavix".
2. **Family profiles:** in Bruno's account, tap the avatar in the top-right corner → add a profile.
3. **Guest mode:** Continuar como convidado (Continue as guest) → open a medication and notice the "not personalised" notice.

## Tech stack

React 18 · TypeScript · Vite 5 · React Router 6

```bash
npm install
npm run dev      # local development
npm run deploy   # build and publish to GitHub Pages
```
